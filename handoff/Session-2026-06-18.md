### Backend state
Backend is healthy. Key detection is working properly after switching from Krumhansl-Schmuckler to Temperley profiles and moving from `chroma_stft` to `chroma_cqt` in `backend/key_detection.py`. The preview endpoint in `backend/main.py` downloads the full preview stream before analysis.

### Data flow for preview key display
1. User clicks preview in `SearchView.tsx` → dispatches `SET_PREVIEW`
2. `AudioPlayerFooter.tsx` receives `previewTrack` from context → fetches `/preview/${track_id}`
3. Backend returns `{stream_url, waveform, key, camelot}`
4. `AudioPlayerFooter.tsx` stores `keyCamelot` in local state and renders `<KeyBadge />`

### The `KeyBadge` component
- Shows plain text when paused.
- Shows animated rainbow gradient when playing (`previewPlaying === true`).
- Uses a React `key` prop hack (`key={playing ? 'playing' : 'paused'}`) to force remount and restart animation on state change.
