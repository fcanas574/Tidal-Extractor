## 2. Context You Need

### FreqBlog API Facts
- Endpoint: `https://api.freqblog.com/api/public/audio-features`
- Auth: `X-API-Key` header (NOT Bearer)
- Speed: ~25-40ms response time
- Free tier available
- Uses Essentia for audio analysis

### Known Limitations
- **Key accuracy**: FreqBlog's Essentia analysis may differ from commercial DJ databases
  - Example: "6am" by ANOTR shows 9A (FreqBlog) vs expected 1A/1B
  - User accepted FreqBlog as "source of truth" despite this
- **Catalog coverage**: Not all tracks are in FreqBlog catalog → fallback to local analysis

### Data Flow for BPM + Key

```
1. Preview clicked
   ↓
2. Cache check (preview_key_{track_id})
   ↓ HIT → Return cached BPM + key
   ↓ MISS
3. FreqBlog API
   ↓ Found → Return BPM + key, cache, display
   ↓ Not found
4. Local librosa analysis
   - Download full preview stream
   - detect_key() → BPM + key
   - Cache + display
```

### Stats Tracking
In-memory counters (reset on restart):
- `hits`: FreqBlog returned data
- `misses`: Track not in FreqBlog, fell back to local
- `errors`: API errors
- `cache_hits`: Cache returned result

Endpoint: `/freqblog/stats`
