# Glossary

Domain and project-specific terms used throughout the vault.

## Music / DJ Terms

### Camelot Wheel (Camelot notation)
A system mapping musical keys to `number + letter` codes (e.g., `8A`, `5B`) for harmonic mixing. Based on the Circle of Fifths:
- **Number (1–12):** position on the circle (Ab=1 ... Db=12)
- **Letter A:** minor key
- **Letter B:** major key

Tracks with compatible Camelot codes mix harmonically. See [[DJ Filters]] · [[Backend key_detection]].

### Harmonic Mixing
Selecting tracks whose keys are compatible (±1 same letter, or same number opposite letter) so transitions sound in-tune. The foundation of the [[DJ Filters]] feature.

### Chroma Features
A 12-bin representation of audio energy per pitch class (C, C#, ..., B). Used by librosa (`chroma_cqt`) to estimate musical key. See [[Key Detection]].

### Temperley Key Profiles
A 12-value profile describing the expected pitch-class distribution for major/minor keys, optimized for pop/rock. Correlated against chroma features to detect key. See [[Backend key_detection]].

### BPM
Beats Per Minute — tempo. Detected via `librosa.beat.beat_track` or sourced from Tidal/FreqBlog metadata.

### Tri-band Waveform
A waveform visualization split into three frequency bands (lows/mids/highs), Rekordbox-style. Generated by wavypy. See [[Waveform Engine]].

## Tidal / Audio Terms

### BTS Manifest
The standard Tidal stream manifest type, used for LOSSLESS and below. See [[Quality Verification]].

### PKCE (Proof Key for Code Exchange)
An OAuth 2.0 extension. **HiRes Lossless requires PKCE-enabled OAuth** (a different manifest type than BTS). See [[Auth Flow]] · [[Gotchas & Traps]].

### ffprobe
A tool from the ffmpeg suite that inspects media files. TidalExtractor uses it to read actual audio bitrate for quality verification. See [[Quality Verification]].

### FakinTheFunk
A tool that misreports FLAC bitrate by sampling instantaneous variable bitrate rather than overall average. TidalExtractor uses ffprobe instead for accuracy. See [[Gotchas & Traps]].

### FreqBlog
An external API (`api.freqblog.com`) providing pre-computed BPM/key/Camelot metadata. Used as a fast tier in hybrid key detection. See [[Backend freqblog]].

## Tech / Project Terms

### wavypy
A git submodule (`backend/wavypy/`, from GabrielJuliao/wavypy) that generates multiband waveform data. Requires a pydub/audioop compatibility shim on Python 3.13+. See [[Backend waveform]] · [[Backend audioop_stub]].

### audioop
A Python stdlib module removed in 3.13 ([PEP 594](https://peps.python.org/pep-0594/)). pydub depends on it; `audioop_stub.py` provides a shim. See [[Backend audioop_stub]].

### Quality Preset
One of four quality tiers (`hi_res_lossless`, `high_lossless`, `low_320k`, `low_96k`), each with a minimum bitrate threshold. Probed top-down per session. See [[Quality Verification]].

### Quality Probe
The one-time-per-session process that empirically discovers which quality preset your account actually delivers, by downloading a 500KB sample and measuring bitrate. See [[Download Pipeline]].

### Orchestrator
`DownloadOrchestrator` — the engine processing the download queue sequentially. See [[Backend downloader]].

### LRU Cache
Least-Recently-Used cache. Used for waveforms (`get_waveform_cached`, maxsize=64). See [[Backend waveform]].
